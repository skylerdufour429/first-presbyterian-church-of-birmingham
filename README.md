# iPad 1st Generation Web App Sandbox

An open-install web interface application mimicking the classic skeuomorphic landscape view of the original 2010 **iPad 1st Generation Home Screen**. 

## Features
- **Codespaces Ready**: Instantly runnable in visual sandbox containers via `.devcontainer`.
- **GitHub Pages Ready**: Hosted static layout architecture ready to be served immediately.

## Running Locally

To execute the local testing Python server workspace, run:
```bash
python server.py
```
Open `http://localhost:8000` in your web browser.
